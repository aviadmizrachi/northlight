Steering mix

    Journey: intro → build → peak → breakdown → rise → drop → outro. Then it starts over with a new key and, on Shuffle, a new climate. Tempo changes restart the groove: the model needs a hard reset to change tempo. Each journey picks one instrument or sample per role: drums, bass, keys, lead, featured instrument and texture. Each phase decides which of them play. Every 16 bars (about 30 s), Evolve changes one instrument or hands one part over to another. The breakdown moves the track to a new key. Orange rows are coming in or going out. Lyria RealTime is an experimental Google model. Use is billed to your Gemini API key. Output is watermarked by Google.
